# 理论依据、符号与图表使用

## 1. 通道统计为何能用于潜在域发现

卷积特征的通道统计可表征部分图像外观变化。AdaIN研究提供了通道均值和标准差与风格表征关系的动机；本项目只提取这两种统计用于聚类，没有执行AdaIN或图像风格迁移。[Huang与Belongie，ICCV 2017](https://openaccess.thecvf.com/content_iccv_2017/html/Huang_Arbitrary_Style_Transfer_ICCV_2017_paper.html)。

标准化后，K-means以欧氏空间内的簇内平方距离为目标；K-means++用于初始化中心。[Arthur与Vassilvitskii，SODA 2007](https://theory.stanford.edu/~sergei/papers/kMeansPP-soda.pdf)。本项目的256维表示、原国家比例、K=2～8范围和最终种子2属于具体实现选择。

Silhouette根据样本的簇内紧凑程度和邻近簇分离程度衡量划分质量。[Rousseeuw，1987](https://www.sciencedirect.com/science/article/pii/0377042787901257)。本项目用固定训练子集评估，并以全量CH/DB、初始化ARI、重采样ARI和组成分析补充判断。该选择发生在源训练数据上；它不证明目标检测性能最优，也不证明两个簇对应天然的纯外观域。

## 2. 两类对抗目标的区别

多专家方案以最小二乘形式区分专家参考与Student特征，损失形式与LSGAN有关。[Mao等，ICCV 2017](https://openaccess.thecvf.com/content_iccv_2017/html/Mao_Least_Squares_Generative_ICCV_2017_paper.html)。这里的生成对象是Student特征，参考来自冻结专家；不是完整图像生成器。实际标签和归约以本项目的[02](02_Kway替换方案.md)为准。

K-way方案以交叉熵预测源域ID，并通过GRL使Student接收相反方向的域梯度。GRL的机制来源可引用DANN。[Ganin等，JMLR 2016](https://www.jmlr.org/papers/v17/15-239.html)。DANN原论文讨论域适应，本项目将该机制用于多个已知源域/潜在源域之间的混淆，训练不接入目标测试图像。

在固定特征分布和足够表达能力的域分类器假设下，最优分类CE对应域条件熵$H(D\mid F)$；提高该量具有降低域可预测性的动机。有限batch、有限模型、动态优化以及任务约束都影响实际结果。这是机制解释，不是对未知测试域风险的保证。

对不均衡域，完全无域信息时的最优预测可以是域先验，CE参照为$H(D)$，不一定是$\log K$。普通准确率的多数类参照和均衡准确率的$1/K$也不同。本项目国家域多数类比例约49.60%，潜在域约53.59%；不能把所有准确率都与33.33%或50%直接比较。

## 3. Triplet为何与域混淆同时存在

类别batch-hard Triplet约束保留类别判别结构，动机是防止只追求域不可分而忽略检测语义。batch-hard的经典来源可参考[Hermans等，2017](https://arxiv.org/abs/1703.07737)。本项目在目标框均值特征上做两尺度、域组合池和域内池挖掘，具体margin、有效anchor及归约是本项目的实现；它不等同于原论文的人员身份采样，也不强制正样本跨域。

三项损失提供检测、类别结构、对抗约束三个优化方向，但不能据此宣称三者必然互补或消除了负迁移。是否有益须由固定配方下的独立组件对照验证。

## 6. 论文实验表的最小字段

每行保留域划分、域数、专家数、判别器数、对抗目标、GRL、Triplet、采样协议、seed、训练轮数、调度周期、best选择规则、测试置信度、七域VOC、七域COCO、训练时间及总训练参数。未来组件列应表示实际启用状态；只在全部其他设置固定时使用“单组件消融”的解释。

推荐同时给出：K选择指标表、簇组成表、四组2×2结构表、七域逐域结果表、配对精度/训练成本变化表。当前数值已导出到[tables](tables/)，其中`all`/`source`/`target`分别为7/3/4域等权平均。

这些论文用于解释机制和术语，不替代本项目的实现证据；具体损失系数、数据边界和实测结论均以归档代码及记录为准。
