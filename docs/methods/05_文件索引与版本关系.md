## 2. 以什么文件认定“当时实际运行”

| 目的 | 应读文件 | 不足以替代它的文件 |
|---|---|---|
| 实际训练逻辑 | 对应`source_snapshot`及日志中的命令 | 当前同名源码、计划文档 |
| 最终超参数 | 每组`run_config.json` | 配置类默认值、README建议值 |
| best模型 | `best_checkpoint.json`+对应best权重 | last权重、最高AP日志点 |
| 真实测试标准 | evaluation_config+运行解码代码快照 | 仅confidence_mode文字标签 |
| 实际数据预算 | epoch_audit、run_config、TXT规范路径 | 配对TXT行数本身 |
| 完成状态 | completion+七域summary与metrics | screen退出或日志末尾百分比 |

### 第一阶段快照

入口为[S1 source_snapshot/train_style_adv.py](../../stage1-latent-domain/comparison_20261005_100ep/source_snapshot/train_style_adv.py)，在加载旧parser和硬编码GPU前将`--experiment`分发至[快照comparison_training](../../stage1-latent-domain/comparison_20261005_100ep/source_snapshot/utils/comparison_training.py)。当前根目录同名训练入口没有这段分发，不能混用。

### K-way 100轮快照

[S2-100 source_snapshot](../../stage2-k-way/kway_comparison_100ep_seed11_20261015/source_snapshot/)是该运行实际执行的冻结源：

- `run_experiment.py`：导入快照并设置数据根路径；其原版本仍使用搬迁前的潜在域地址。
- `new_experiments/kway_domain/{training,discriminator,verify,check_smoke}.py`：实际四组训练与标定。
- `new_experiments/kway_domain/{launch,worker,report}.py`：100轮、seed11、七域VOC主指标的调度与报告；不同于项目根目录60轮版本。
- `standard_utils_bbox.py`及`new_experiments/kway_domain/evaluation.py`：最终标准置信度测试。
- `utils/utils_bbox.py`：保留训练回调当时的旧不确定性解码。它与上项用途不同。

## 3. 散落的历史与扩展分支

这些文件与研究历史有关，但不属于01～04主线的全部默认行为。

| 文件/目录 | 作用 | 使用边界 |
|---|---|---|
| [README_style.md](../../README_style.md)、[dg_config.py](../../dg_config.py) | 更早的K=3、feat1、hard/dense/Top-2软风格路由 | 不套用到K=2正式对照 |
| `style_cache/`、`utils/style_router.py`、`utils/style_assignment.py`、`utils/style_adv_trainer.py` | 距离缓存、soft membership、熵置信度和专家加权 | 当前01～04不使用 |
| [latent_dg_config.py](../../latent_dg_config.py)、[train_latent_ablation.py](../../train_latent_ablation.py) | K=2 hard/soft专家与K-way扩展配置、profile | 每个profile单独定义目标/日程，不等于主线Hard CE+GRL |
| [utils/latent_membership.py](../../utils/latent_membership.py) | 硬/软离线membership及缓存 | 研究分支 |
| [utils/latent_ablation_training.py](../../utils/latent_ablation_training.py) | 扩展训练器、membership数据集 | 研究分支 |
| [utils/latent_v2.py](../../utils/latent_v2.py) | pooled分类器、balanced CE、V2对抗器 | 不替代主线的普通CE定义 |
| [utils/latent_structure.py](../../utils/latent_structure.py) | 条件式风格判别器、归一化替换和风险归约 | 其他结构消融 |
| [utils/online_latent_centers.py](../../utils/online_latent_centers.py) | 在线中心 | 当前固定域主线未使用 |
| [utils/latent_validation.py](../../utils/latent_validation.py) | 显式验证解码口径及COCO callback | 扩展验证流程 |
| `tools/run_latent_suite.py`、`run_latent_screen_worker.py`、`run_kway_stage_worker.py` | 扩展suite、v2 hard_kway/GRL等任务 | 看其config与产物，不能混认作01～04入口 |
| `tools/audit_latent_training.py`、`audit_latent_evaluation.py`、`summarize_evaluation_audit.py` | 历史训练/指标审计 | 有助追溯，不是正式训练入口 |
| `tools/run_deterministic_parity.py` | 在独立进程固定CUDA后端 | 用于迁移一致性排查 |
| [stage1 evaluation_audit](../../stage1-latent-domain/evaluation_audit_20261007/) | hard_expert/soft_expert/hard_kway/soft_kway的统一复测 | 独立历史扩展，不放入主四组结果表 |

同名`hard_kway`在不同profile可能表示先验混淆、普通CE或其他结构；应以`adversarial_objective`、构建的head、实际loss和GRL代码确认，不按名字推断。

## 4. 项目外依赖

专家仓库位于`/data4/czh/yolov8-cluster/yolov8-pretrain/`，正式专家说明见[专家README](../../../yolov8-pretrain/results/expert_pretrain_20261004_200ep/README.md)。本项目只消费其backbone权重，并不包含所有专家训练入口。图像实体可位于原数据项目；本项目TXT保存规范路径。

当前IDE中可能打开的`/data4/czh/beifen/domain_splits/`是项目外目录，主线实际记录引用的是归档S0的`domain_splits`及原运行路径；本资料没有将该备份当作正式训练输入。

当前证据目录和全部相关入口的结构化索引见[tables/file_inventory.csv](tables/file_inventory.csv)。
